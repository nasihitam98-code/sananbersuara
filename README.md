# Pemilihan Warga

Aplikasi web pemilihan warga (RT/RW) berbasis Laravel dan Filament.

- **Mode Dadakan**: pemilih memindai satu QR, mencari nama, memasukkan PIN, lalu memilih. Untuk rapat/penjaringan dengan banyak peserta sekaligus.
- **Mode Resmi**: meja izin + laptop bilik per RT, untuk pemilihan Ketua RT dan Ketua RW.
